# STONKERICA

Independent America.Fun × StonkFun integration concept. React/Vite interface with live read-only StonkFun proxy, market search, pagination, watchlist, token lookup and creator-fee lookup. Actual response fields are read under token.market. Never presents platform-wide tokens as our own launches.

Run `npm ci`, then `npm run dev -- --port 5186`; `npm run build` creates frontend assets. Vercel API adapter included. Server proxy permits GET reads from a fixed upstream and allowlisted paths only.

USD1, $20K opening cap and enhanced rewards are target settings, not active launch features. The launch form saves a local plan and exports JSON; it does not submit a transaction. Existing protocol standard creator fee is shown separately. No official partnership is asserted. Solana Phantom/Solflare browser wallet connection requests accounts only. No secret key required for public API reads.
